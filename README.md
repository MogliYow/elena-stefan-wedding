# Elena & Stefan — wedding invitation

One invitation, based on the ivory/gold envelope design. React, TypeScript, GSAP, Vite.

## Run
Node.js 22.12+.
`npm install`
`npm run dev`
`npm run build`
`npm run preview`

Production output: dist. Render build: npm install && npm run build. Netlify/Vercel: Vite, output dist.

Content: src/data/invitation.ts. June 12, 2027 and Skopje are demonstration content. Photos are illustrative Unsplash photographs. RSVP explicitly runs in demo mode and sends/stores no guest data. Set mode=formspree and a real endpoint before client delivery. Music is an optional original synthesized ambient sequence, activated only after an explicit click.

Features: layered 3D envelope opening, horizontal seal monogram, keyboard controls, reduced-motion support, responsive sections, scroll reveal, countdown, Maps link, validated RSVP demo, replay, music toggle.
